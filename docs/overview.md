# О проекте TgMon (Telegram Monitor)

**TgMon** — это продвинутая аналитическая платформа для мониторинга, глубокого анализа и сравнения Telegram-каналов. Сервис позволяет владельцам каналов и маркетологам отслеживать эффективность контента, анализировать конкурентов и принимать data-driven решения с помощью математических алгоритмов и искусственного интеллекта.

## 🚀 Ключевые возможности

1. **Глубокая аналитика вовлеченности**
   - Сбор реальных данных: просмотры, реакции, комментарии, репосты (через MTProto API).
   - Подсчет **ERR** (Engagement Rate by Reach) — истинной вовлеченности аудитории.
   - Отслеживание жизненного цикла поста (**Content LTV**) — как долго пост собирает просмотры после публикации.

2. **Продвинутый скоринг (Effective Point - EP)**
   - Уникальный алгоритм **EP (Effective Point)** оценивает канал от 0 до 100 баллов. 
   - Учитывает динамику роста (CEI), читаемость (VR) и вовлеченность (ERR).
   - Использует Z-нормализацию для честного сравнения каналов разных размеров внутри одной ниши, сглаживая шум мелких каналов с помощью логарифмического "Коэффициента доверия" (Confidence Factor).

3. **Конкурентный анализ и бенчмаркинг**
   - Единый дашборд для сравнения своего канала с конкурентами (доля аудитории, разница в росте, разница в частоте публикаций).
   - Выявление **"Лучшего времени для постинга"** на основе анализа того, когда посты конкурентов собирают максимальный ERR и охваты.
   - Построение графа цитирования (Citation Network) — кто кого репостит и упоминает.

4. **AI-Аналитика (Искусственный Интеллект)**
   - Автоматическая генерация портрета аудитории (Persona).
   - Выжимка главных тем и трендов конкурентов (Trend Spotter).
   - Формирование action-планов для развития канала на основе собранной статистики.

## 🛠 Технологический стек

Сервис построен на современном, быстром и масштабируемом стеке:

* **Frontend / UI:** 
  - **Next.js 15** (App Router) + React 19
  - **Tailwind CSS** (стилизация, dark-mode дизайн)
  - **Recharts** (интерактивные графики и хитмапы)
  - **Mermaid.js** (рендеринг графов связей)

* **Backend / API:**
  - Node.js (встроенные API-роуты Next.js)
  - Выделенные фоновые воркеры (Workers) для сбора данных

* **Сбор данных (Парсинг):**
  - **GramJS (Telegram MTProto API)** — сервис работает как полноценный Telegram-клиент. Это позволяет собирать точные данные без ограничений публичного веб-интерфейса (включая количество реакций, комментариев, приватные каналы).

* **База данных:**
  - **PostgreSQL** — реляционная СУБД для надежного хранения истории.
  - **Prisma ORM** — типизированная работа с базой данных.
  - Использование расширения `pg_trgm` для быстрого нечеткого поиска по текстам постов.

## 🏗 Архитектура

1. **Коллектор (Worker):** Регулярно опрашивает добавленные каналы через Telegram API. Сохраняет снапшоты (снимки) количества подписчиков, скачивает новые посты, фиксирует просмотры и реакции.
2. **Аналитическое ядро:** Считает агрегированные метрики, тренды, дельты за 24ч/7д/30д, Z-оценки и тепловые карты активности (Heatmaps) в памяти (in-memory) для максимального быстродействия дашборда.
3. **UI-Слой:** Выводит данные в виде интерактивных таблиц, графиков и AI-отчетов с использованием современных паттернов UX/UI дизайна.
