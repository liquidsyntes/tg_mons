# API Reference

Проект предоставляет встроенный REST API через маршруты Next.js (App Router Route Handlers), находящиеся в `src/app/api/`. API используется фронтендом для получения метрик и управления каналами.

## Общие принципы
- Все ответы API отдаются в формате `application/json`.
- В случае ошибки API возвращает соответствующий HTTP статус-код (400, 401, 404, 500) и JSON с ключом `error`.
- Даты возвращаются в формате ISO 8601 UTC.

## Channels API (Каналы)

### `GET /api/channels`
Получение списка всех отслеживаемых каналов с базовой информацией.

### `POST /api/channels`
Добавление нового канала в мониторинг.
**Тело запроса:**
```json
{
  "identifier": "username или t.me ссылка"
}
```

### `GET /api/channels/[id]`
Получение детальной информации о конкретном канале.

### `PATCH /api/channels/[id]`
Изменение настроек канала.
**Тело запроса:**
```json
{
  "isActive": true,
  "isMine": false
}
```

### `DELETE /api/channels/[id]`
Мягкое отключение канала от мониторинга.

### `PATCH /api/channels/[id]/favorite`
Добавление/удаление канала из избранного.

### `GET /api/channels/[id]/ltv`
Получение данных о Lifecycle (LTV) контента канала — как долго посты набирают просмотры после публикации по часам.

### `GET /api/channels/[id]/network`
Получение графа упоминаний и репостов (Network Graph).

## Stats API (Метрики и Статистика)

### `GET /api/stats/overview`
Главная сводка метрик для дашборда (Общие тренды, рост аудитории, ER).

### `GET /api/stats/dashboard`
Агрегированные данные для отрисовки графиков на главной странице.

### `GET /api/stats/channel/[id]?period=7d`
Таймсерии для графиков конкретного канала (подписчики, посты).
**Параметры:** `period` (`24h`, `7d`, `30d`).

### `GET /api/stats/compare`
Данные для детального сравнения нескольких каналов.

### `GET /api/stats/best-time`
Расчет "Лучшего времени для публикации" (Best Time to Post) на основе тепловой карты конкуренции и ER в нише.

### `GET /api/stats/trends`
Аналитика растущих и падающих метрик в нише.

## AI API (Искусственный Интеллект)

*Эти маршруты формируют промпты на основе метрик и запрашивают LLM (через OpenRouter).*

### `GET /api/ai/summary`
Сводный текстовый анализ состояния канала.

### `GET /api/ai/persona`
Генерация портрета аудитории (Persona) на основе анализа контента.

### `GET /api/ai/action-plan`
Пошаговый план развития канала для владельца.

### `GET /api/ai/compare`
Текстовое сравнение "моего канала" с выбранным конкурентом.

### `GET /api/ai/trends`
Выделение главных тем и трендов у конкурентов.

## Worker & System API

### `GET /api/health`
Healthcheck эндпоинт. Проверяет жизнеспособность фонового воркера (отставание `lastCollectedAt`) и статус БД.

### `POST /api/collect/run`
Ручной триггер запуска цикла сбора MTProto Worker.
**Требует:** Заголовок `Authorization: Bearer <COLLECT_API_TOKEN>`.
