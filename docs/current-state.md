## Реализовано в исходниках

- `src/worker/fetcher.ts` использует типы установленного Telegram SDK для сущности, полного канала и параметров/результата загрузки сообщений. В ответе `CheckChatInvite` поле chat читается после сужения по className без `any`.
- Ошибки в `withRateLimitAndRetry` принимаются как `unknown`; проверяемое чтение `errorMessage` и `seconds` сохраняет приоритет числового seconds, FLOOD_WAIT fallback, число попыток, паузы и повторный выброс исходной ошибки.
- `src/worker/retry-policy.ts` принимает `unknown` и безопасно извлекает текст для состояния канала, включая строку, null и объект с message. Маршрутизация Telegram Bot API, порог отключения и формат сообщения не менялись.
- Добавлены 11 проверок форм ошибок и поведения повторов. Схема БД, миграции, зависимости и публичное поведение не менялись.
