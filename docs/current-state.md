Снимок: 26 октября 2026 года. База задачи Issue #48: `eed7868`, ветка `codex_fix_issues`, upstream `origin/codex_fix_issues`; рабочее дерево до изменений было чистым. Перед следующей задачей проверить Git заново. Это состояние исходников и локальных проверок, не заключение о production.

## Реализовано в исходниках

- Карта связей канала показывает роль в инфополе, входящие и исходящие связи за 30 дней, средний подтверждённый отклик, топ цитируемых постов и последние цепочки между доступными отслеживаемыми каналами.
- Для точных связей worker сохраняет nullable `Mention.targetMessageId` из Telegram-пересылки или прямой ссылки на пост. Старые ссылки на конкретный пост можно сопоставить по тексту цитирующей публикации. Без точного поста цепочка остаётся видимой с задержкой `н/д`.
- Миграция `20261026153255_add_mention_target_message_id` добавляет nullable BIGINT-колонку без изменения существующих строк. Описание формул, API и БД обновлено.

## Ограничения и следующий шаг

`originRatio` при нуле исходящих связей равен `null`, а роль определяется по счётчикам. Старые пересылки без ID исходного поста входят в профиль и цепочки, но не получают придуманную задержку. Ссылка `t.me/c` для канала без username открывается только при наличии доступа в Telegram.
