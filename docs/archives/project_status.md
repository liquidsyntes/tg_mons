# Текущий статус проекта TG Monitor и контекст

## Что было сделано в последних сессиях:
1. **Виджет "Окно возможностей":** Алгоритм поиска 2 лучших часов для публикации постов (основано на тепловой карте) переписан так, чтобы высчитывать точную дату и время от текущего момента пользователя.
2. **Избранное (Watchlist):** Добавлен флаг `isFavorite` в Prisma. Реализовано добавление 3-4 конкурентов в избранное с выводом их в отдельный блок на главном дашборде.
3. **Архитектура AI-отчетов (Строгий JSON):** Мы полностью ушли от генерации чистого Markdown силами ИИ. Теперь ИИ (OpenRouter) возвращает строгий JSON по заданным схемам. Это позволило создать красивые, кастомные React/Tailwind компоненты с таблицами, прогресс-барами и карточками (`AISummaryReport.tsx`, `AICompareReport.tsx`).
4. **Архив AI-Отчетов (БД):** Создана модель `AiReport`. Все генерируемые отчеты сохраняются в базу данных. Появился раздел `/reports` со списком отчетов и страница `/reports/[id]` для их просмотра.
5. **Анализ динамики (Evolution):** Добавлена возможность выбрать чек-боксами 2 исторических отчета в архиве и сгенерировать анализ прогресса (компонент `AIReportEvolution.tsx`). ИИ отслеживает, какие рекомендации были внедрены, а какие проигнорированы.
6. **Action Plan (Пошаговое руководство):** Кнопка под любым отчетом, которая превращает аналитику в конкретный пошаговый план действий на 10 пунктов (компонент `AIActionPlan.tsx`).
7. **Экспорт:** Сохранена возможность экспортировать данные обратно в классический `.md` файл по нажатию кнопки.

## Промпт для загрузки контекста в новом диалоге

Скопируйте текст ниже (начиная со слова "Привет!") и отправьте его ИИ в начале новой рабочей сессии:

```text
Привет! Мы продолжаем разработку проекта "TG Monitor" (TgMon) на стеке Next.js 15 (App Router), React, Tailwind CSS и Prisma (SQLite).

### Суть проекта:
Сервис для глубокой аналитики Telegram-каналов и конкурентной разведки с упором на крутой визуальный AI-анализ контента.

### Что уже реализовано:
1. Сбор статистики, расчет "Окна возможностей" для постинга на основе тепловой карты.
2. Избранное (Watchlist) для конкурентов на дашборде.
3. Система AI-Отчетов (модель AiReport). Все отчеты хранятся в БД и рендерятся через кастомные React-компоненты.
4. У нас есть 4 вида отчетов (для каждого свой JSON-формат ответа ИИ и свой .tsx компонент):
   - Summary (Контент-анализ)
   - Compare (Сравнение двух каналов по правилам "Анти-Сикофансии" - ИИ обязан быть объективным, не льстить моему каналу, приводить цитаты)
   - Evolution (Анализ динамики: сравнение 2-х старых отчетов, выявление внедренных и проигнорированных рекомендаций)
   - Action Plan (Генерация 10 конкретных пошаговых действий на основе любого отчета).
5. Экспорт отчетов в Markdown.
6. Для AI используется OpenRouter с `response_format: { type: 'json_object' }`.

### Технические нюансы (ОЧЕНЬ ВАЖНО для тебя):
- ОС: Windows. 
- Prisma-Баг: Из-за блокировки файлов (query_engine.node) сервером Next.js в режиме dev, при любом изменении schema.prisma и запуске `prisma db push`, генерация клиента падает с EPERM. Это решается ТОЛЬКО ручным рестартом сервера `npm run dev` пользователем. Ты можешь делать push, но должен предупреждать об этом.
- Мы не используем Markdown-ответы от ИИ напрямую в UI. Всегда запрашиваем строгий JSON и мапим его в красивые Tailwind-блоки.

Подтверди, что ты понял контекст, архитектуру и технические нюансы. Я сейчас опишу следующую задачу.
```
