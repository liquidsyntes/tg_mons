# Отчет о разработке проекта TG Monitor

**Дата составления:** Август 2026
**Репозиторий:** [github.com/liquidsyntes/tg_mons](https://github.com/liquidsyntes/tg_mons)

## 📌 О проекте
**TG Monitor** — это мощная аналитическая панель (дашборд) для мониторинга Telegram-каналов и глубокого конкурентного анализа. Приложение позволяет отслеживать динамику аудитории, оценивать вовлеченность, анализировать контентную стратегию конкурентов с помощью ИИ и получать мгновенные уведомления об аномалиях.

## 🛠 Технологический стек
* **Frontend:** Next.js (App Router), React, Tailwind CSS, Lucide React (иконки), Recharts (графики).
* **Backend:** Next.js API Routes, Node.js.
* **База данных:** SQLite + Prisma ORM.
* **Сбор данных:** Telegram MTProto API через библиотеку `telegram` (GramJS).
* **AI-интеграция:** OpenRouter API (модели Google Gemini) для анализа текстов.

## 🚀 Реализованный функционал

### 1. Сбор и агрегация данных (Worker)
* Настроен фоновый скрипт-коллектор (`src/worker/collector.ts`), который авторизуется в Telegram как пользователь.
* **Снапшоты:** Регулярно собирает точное число подписчиков каналов и сохраняет исторические срезы.
* **Сбор контента:** Скачивает последние посты каналов, подсчитывает просмотры и сохраняет тексты постов в БД.
* **ERR и Вовлеченность:** Автоматический расчет метрики ERR (Engagement Rate by Reach) на основе просмотров за последние 7 дней.

### 2. Главный Дашборд
* Карточка "Моего канала" с ключевыми показателями (Подписчики, Просмотры, ERR, Прирост).
* Таблица конкурентов с сортировкой, дельтами прироста за 24ч, 7 дней и 30 дней.
* **Экспорт в CSV:** Кнопка для мгновенной выгрузки текущей аналитики по всем каналам в Excel/CSV.

### 3. Детальная аналитика канала (Страница канала)
* **Динамика участников:** Линейный график изменения числа подписчиков. Реализована функция наложения (сравнения) кривой конкурента с графиком "Моего канала".
* **Публикационная активность:** Столбчатая диаграмма частоты выхода постов.
* **Тепловая карта (Heatmap):** Матрица "Дни недели / Часы", позволяющая визуально выявить расписание публикаций конкурентов и найти окна с наименьшей конкуренцией.

### 4. AI-Аналитика контента
* Интеграция с ИИ через OpenRouter.
* **Саммари контента:** Нейросеть изучает до 50 последних постов канала и выдает структурированный отчет: основные темы, tone of voice, методы вовлечения, реклама, сильные стороны и советы по улучшению.
* **Сравнительный анализ:** Возможность столкнуть контент конкурента с контентом "Моего канала". ИИ анализирует тексты обоих каналов и выдает рекомендации, как превзойти конкурента, перенимая его сильные фишки.

### 5. Система алертов (Уведомлений)
* Бот-информер в Telegram. Если при очередном сканировании воркер обнаруживает резкий скачок отписок или подписок (более 1% или более 500 человек) относительно предыдущего снапшота, он отправляет срочное уведомление в личный Telegram пользователя через Bot API.

## 📁 Структура проекта (Навигация)
* \`prisma/schema.prisma\` — структура базы данных (модели Channel, ChannelSnapshot, Post).
* \`src/worker/\` — логика фонового сбора данных из Telegram (GramJS).
* \`src/app/api/\` — backend-эндпоинты (статистика, AI-генерация `/api/ai/summary`, `/api/ai/compare`).
* \`src/app/channel/[id]/\` — frontend детальной страницы канала с графиками.
* \`src/components/\` — переиспользуемые UI-компоненты (HeatmapChart, DeltaBadge и т.д.).
* \`src/lib/metrics.ts\` — математика расчета дельт, ERR и тепловой карты.

## 💻 Как запускать проект
Для полноценной работы системы нужно запустить одновременно веб-интерфейс и фоновый сборщик данных. Для этого настроена единая команда:

\`\`\`bash
npm run dev:all
\`\`\`
*(Эта команда через npm-run-all параллельно запускает \`next dev\` на порту 3000 и \`npm run worker\` для сбора статистики).*
