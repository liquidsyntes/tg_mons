# Протокол synthetic-v2, Issue #92

Статус: критерии и платный эксперимент до 140 запросов, предлагаемый бюджет $1 согласованы пользователем 16 ноября 2026 до просмотра контрольных результатов. Исходный manifest и набор зафиксированы коммитом a4cb449.

## Набор и ограничения

200 оригинальных синтетических текстов, 50 семейств. В каждом семействе русский и украинский варианты, короткая и расширенная редакции. 104 calibration и 96 control, по 100 текстов каждого языка, 100 положительных и 100 отрицательных. Семейства p1-p13/n1-n13 относятся к calibration, остальные к control. Тексты не заимствованы из v1 или Telegram. Вымышленные площадки не являются реальными контактами.

Четыре редакции одного семейства зависимы: эффективное разнообразие составляет 50 сценариев, не 200 независимых наблюдений. Расширенные редакции используют общий редакционный абзац. Разделение по семействам исключает переводы и варианты одного сценария между частями; общие языковые конструкции сохраняются. Это ограниченный синтетический стресс-тест, а не репрезентативная выборка. Автоматическая проверка точных дублей не доказывает отсутствие семантически близких сценариев.

## Разметка

Положительный пример приглашает на одно будущее событие с определимой датой и практической деталью участия. Регистрация, онлайн-формат, бесплатный вход и напоминание участникам допустимы. Программа одного фестиваля считается одним событием. Подборка независимых событий отрицательна. Перенос с новой определимой датой и приглашением положителен; отмена или перенос без даты отрицательны. Ретроспектива, новость, реклама товара/курса без общей даты и тизер без условий участия отрицательны.

Относительная дата разрешается относительно publishedAt в timeZone. p25 проверяет переход года: 2026-12-31 21:30 UTC, Europe/Kyiv, завтра = 2027-01-01. Остальные публикации датированы 16 ноября 2026. Сегодня = 16 ноября, завтра = 17 ноября, послезавтра = 18 ноября. Даты в прошлом трактуются относительно публикации, не дня запуска.

expected.event используется как совместимая структура оценщика. title содержит исходную фразу анонса как каноническое обозначение сценария; это НЕ эталон естественного заголовка генеративной модели. prices не оценивается этим экспериментом. Не запускать сравнение полей извлечения по v2 и не заявлять их качество. Decisions получает только id/text, без publishedAt/timeZone: временной контекст разметки не означает, что модель получила его. Изменять production-промпт в этом эксперименте нельзя.

## Согласованные критерии

На control: precision >= 0.98; recall >= 0.90, прирост к Jev >= 0.10 абсолютного значения; 0 FP отдельно в recap, past, cancelled и advertising. Unknown <= 1%, иначе результат недостаточен. Стоимость и сумма длительностей пакетов каскада <= 3 соответствующих значений Jev. Неизвестная стоимость не равна нулю и не позволяет подтвердить ценовой критерий. Любые изменения критериев версионировать до запуска контрольной части.

Recall оценщика считается по известным ответам; обязательно читать его вместе с coverage/errors. Unknown нельзя считать правильным отрицательным ответом. Отдельно публиковать modelSelection и итог selection с production-фильтром дайджестов. Результаты вариантов пакетов не использовать для выбора лучшего результата задним числом.

## Прогоны и бюджет

Основные: Jev и Gemini по 200 примеров, по 20 последовательных запросов; затем Gemini только на валидных отрицательных ответах Jev, не отфильтрованных локально, максимум 20 запросов. Первая ступень нового набора вызывается заново, baseline v1 несовместим по хешу.

Устойчивость: обе модели на всех 200 примерах в двух дополнительных вариантах: within-batch (обратный порядок в прежних пакетах) и regroup (сортировка SHA-256(seed,id), seed issue92-v1). Это ещё 80 запросов. Всего максимум 140 запросов, 1400 отправленных примеров. Дополнительный каскад для вариантов порядка не включён в этот бюджет.

Историческая стоимость из #89 для коротких v1: Jev 0.00181839/80 и Gemini 0.00638630/80 USD. Линейный ориентир для 600 Jev + максимум 800 Gemini равен 0.077501925 USD. Это не текущая котировка и не верхняя граница: длина текстов, состав пакета, тариф и alias модели меняются. Предлагаемый предел расходов 1 USD. Для строгой защиты лимита требуется лимит на стороне провайдера; локальная остановка после usage не ограничивает цену уже отправленного запроса. Разрешение пользователя получено 16 ноября 2026. Не выходить за согласованный объём; при неизвестной стоимости прекратить новые запросы.

## Воспроизведение

Из корня проекта, выходной файл должен отсутствовать:

```bash
npx tsx scripts/evaluate-events.ts plan --dataset src/lib/events/eval-data/dataset-v2.json --model '~typesafe/jev-latest' --limit 200 --order original --out /tmp/jev-v2-plan.json
npx tsx scripts/evaluate-events.ts plan --dataset src/lib/events/eval-data/dataset-v2.json --model google/gemini-decision-1 --limit 200 --order regroup --seed issue92-v1 --out /tmp/gemini-v2-regroup-plan.json
```

Повторить plan для обеих моделей и original/within-batch/regroup. plan не требует ключа и не обращается к сети. capture использует те же параметры с --allow-paid yes только после разрешения. Перед вызовами сохраняются точные payloads и хеши; ответы записываются после каждого запроса. Автоматических повторов нет. После транспорта с неизвестным исходом не запускать тот же эксперимент повторно без отдельного решения.

Сохранённые ответы воспроизводятся командами evaluate/compare/cascade из README. Для одиночных моделей evaluate запускать без split и с --split control; categories/languages/splits входят в отчёт. cascade возвращает общую, calibration, control и категории. Сумма durationMs является временем последовательного CLI, не production latency. При фильтрации split стоимость относится ко всему прогону.

Отчёт платного этапа должен содержать матрицы ошибок, precision/recall/coverage, ошибки по ID/семействам, известные расходы и неизвестные расходы, задержки и различия пакетных вариантов. Итоговые измерения и рекомендация приведены в [отчёте](live-v2/REPORT.md). Генеративное извлечение не измерялось; production остаётся вне задачи.
